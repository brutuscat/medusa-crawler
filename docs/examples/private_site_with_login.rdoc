== Crawl a private site with a login form

Medusa is an HTTP crawler, not browser automation. For a site with a conventional server-rendered
login form, authenticate first with +Net::HTTP+ and then give the session cookie to Medusa.

The runnable code is in +examples/private_site_with_login.rb+:

    MEDUSA_USERNAME=user MEDUSA_PASSWORD=secret ruby examples/private_site_with_login.rb

The example submits +username+ and +password+ to the configured login endpoint, obtains the
+Set-Cookie+ response header, and starts Medusa with +cookies:+ and +accept_cookies:+ enabled.
It also uses the same User-Agent for the login request and the crawler. Some sites bind a session to
that header, so changing it after authentication can invalidate an otherwise valid cookie.

=== Scope

This pattern is suitable for normal form POST logins that return a session cookie. JavaScript
authentication, multi-step or site-specific CSRF flows, MFA, OAuth, and CAPTCHA need site-specific
handling before Medusa begins crawling.

=== Authenticated-crawl smoke test

+spec/smoke/private_site_with_login_smoke.rb+ exercises the example against the public login at
https://the-internet.herokuapp.com. It signs in as +tomsmith+, crawls +/secure+, and extracts this
authenticated-page text:

    Welcome to the Secure Area. When you are done click logout below.

The smoke test runs after changes are merged to +main+ and again before a tagged gem release is
published. It retries the public test service up to three times, with a five-minute job timeout.

=== Why the smoke test does not log out

The quoted text is UI copy for a person using the demonstration website; it is not an instruction
for the crawler. The smoke test fetches only the protected page and finishes. Its cookie is local to
the short-lived CI process and disappears when that process exits.

Following a logout link would add an unnecessary, site-specific state-changing request. A crawler
should not follow logout links automatically; in a real authenticated crawl, exclude them explicitly
when they are in scope.
