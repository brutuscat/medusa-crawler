== Download linked files

Medusa follows +a[href]+ links by default. The example in +examples/file_download.rb+ observes every
linked response and writes successful non-HTML responses to a destination directory, using the last
component of the URL path as the filename.

It does not rely on a particular URL pattern such as +/download/+. Bound the crawl with
+focus_crawl+, +skip_links_like+, or a depth limit when a site has large or untrusted downloads.
